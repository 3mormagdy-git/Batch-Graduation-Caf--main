# Cafe POS Dashboard

A responsive cafe POS/admin dashboard built with React, Vite, Tailwind CSS, and Lucide icons. Charts are rendered with inline SVG.

## Run locally

```sh
npm install
npm run dev
```

Run `npm run build` to create a production build and `npm run lint` to check the source.

Dashboard data lives in `src/data/dashboard.js`. Menu item data and photos are kept in `src/data/menu.js` and `public/images/menu/`.
